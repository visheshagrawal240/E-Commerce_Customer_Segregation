# Online Retail II — Data Analysis

## 📌 Overview
This project analyzes online retail transactions to identify sales trends, understand customer behavior, and extract useful business insights using Python and machine learning.

## 📂 Dataset
**File:** `online_retail_II.csv`

Contains transaction details such as invoice numbers, products, quantities, prices, customer IDs, dates, and countries.

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn

## ⚙️ Workflow
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales and customer behavior analysis
- Customer segmentation using clustering (if implemented)
- Data visualization

## 🎯 Objective
To discover sales patterns, identify valuable customers, and support data-driven business decisions.
